# 🔐 Password Strength Checker

A simple Python-based Password Strength Checker that analyzes a password based on different security criteria and tells the user whether the password is weak, medium, or strong.

This project was created as part of my cybersecurity learning journey.

## 🚀 Features

- Checks password length
- Checks for uppercase letters
- Checks for lowercase letters
- Checks for numbers
- Checks for special characters
- Gives a strength rating:
  - Weak
  - Medium
  - Strong

## 🛠️ Technologies Used

- Python
- Regular Expressions (Regex)
